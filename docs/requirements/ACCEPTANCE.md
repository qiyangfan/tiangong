# 可执行验收清单 / Definition of Done

本文件是**未来实现的验收规范，不表示当前已完成**。

## 平台行为

- [ ] 全新环境按 README 可使用单一命令启动服务、Web、MySQL（移动端由微信开发者工具编译）
- [ ] 首次初始化不会生成固定生产默认密码，Bootstrap 管理员凭证通过安全交互/环境生成
- [ ] 登录失败、过期、禁用账号、强制登出均有明确状态；密码不会记录日志
- [ ] 用户、角色、菜单、权限、字典、参数、日志、文件、生成器 P0 均有真实 DB/API/Web 路径
- [ ] 服务端拒绝无权访问、水平越权和绕过前端隐藏菜单的直接请求
- [ ] 文件上传限制类型、尺寸、名称，不允许路径遍历、任意可执行文件上传和越权下载
- [ ] 生成器可重复运行、不会静默覆盖自定义代码，示范 CRUD 包含测试与迁移
- [ ] API 契约与公开 DTO 经 OpenAPI 校验，不泄露密码哈希等内部字段
- [ ] 请求日志、操作审计、登录审计可关联 requestId；敏感字段脱敏
- [ ] 所有数据库约束/迁移可从空库初始化，重建/备份恢复流程演练成功

## 三端与 UI

- [ ] Web 真实登录、权限菜单、分页/搜索/表单校验/错误状态/键盘可用性
- [ ] 微信开发者工具可编译并连接真 API，登录凭证安全存储、退出清理
- [ ] Web 写入的 SampleRecord 小程序可查看；小程序变更后 Web 可查到
- [ ] Web 与小程序实际调用相同 API 契约，不使用假成功 Mock

## CI 与交付

- [ ] lockfile 固化；`pnpm lint/typecheck/test/build` 通过
- [ ] DB integration tests 与关键 e2e 在 CI 真实运行，不在 CI 中跳过
- [ ] 容器健康检查、优雅退出、环境变量缺失时快速失败
- [ ] `README.md`、API 文档、ADR、OpenSpec 与实现一致
- [ ] `SECURITY.md`、LICENSE 策略、第三方依赖许可证、安全扫描与升级策略完善
- [ ] 交付报告注明已验证命令、失败记录、未覆盖项，禁止虚假“全部通过”

## 关键反向用例

- [ ] 未认证请求 / 401
- [ ] 无权限账户直接调用管理员 API / 403
- [ ] 通过前端隐藏按钮绕过鉴权 / 必须失败
- [ ] 异常输入、SQL 注入、XSS、文件路径遍历 / 被拦截或安全编码
- [ ] 并发更新导致唯一约束/状态冲突 / 得到确定性错误，不出现部分写入
- [ ] 生产环境缺失 secret / 启动失败且不打印 secret
