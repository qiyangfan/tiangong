# 建设里程碑

- **M0 基线与研发治理**：确认依赖版本兼容性、许可、目录、环境、Constitution、AGENTS、ADR、OpenSpec、CI 门禁。输出可运行空三端与健康检查。
- **M1 安全与核心底座**：DB migration、种子管理、认证、用户、角色、菜单、权限守卫、审计、Web 登录与基础布局、miniapp 登录。
- **M2 系统管理**：字典、参数、操作/登录日志、文件上传、分页筛选、错误码、API 文档；完成 Web 管理界面。
- **M3 开发工具与完整纵向闭环**：通用元数据/代码生成器、SampleRecord 从 DB 到 Web/miniapp、生成产物可测试且不覆盖手写文件。
- **M4 质量与交付**：端到端/权限负例/安全测试、备份恢复/迁移、构建、Docker Compose、部署文档、验证报告。
- **M5 P1 能力（单独迭代）**：公告/会话/定时任务/组织/岗位/数据权限/导入导出。只有明确需求才进入 backlog，不阻塞 M4。

每个里程碑必须包含：代码、OpenSpec 更新、测试结果、可操作 README、已知限制和可回滚策略。不得将未完成的 P0 移入“后续优化”以宣称交付。
