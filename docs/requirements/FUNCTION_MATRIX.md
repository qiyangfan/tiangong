# 通用后台能力矩阵（以 RuoYi 为能力基准）

**这是平台脚手架，绝不含行业业务模块。** P0=首版强制交付；P1=按明确需求启用的通用扩展；P2=非默认能力；X=不预建。P0 必须可运行、可测、可部署，不接受空页面。

| 能力                     | RuoYi 参照     | 本脚手架决策 | 最低交付要求                                                              |
| ------------------------ | -------------- | ------------ | ------------------------------------------------------------------------- |
| 管理员登录/退出          | 基础登录       | **P0**       | 账号密码、安全哈希、token/cookie 策略、注销、登录失败保护                 |
| 当前用户/个人中心        | 用户信息       | **P0**       | profile、修改密码、更新信息、头像可选                                     |
| 用户管理                 | 用户管理       | **P0**       | CRUD、启停、重置密码、搜索、分页、唯一约束                                |
| 角色管理                 | 角色管理       | **P0**       | RBAC、角色与权限关联、基础角色                                            |
| 菜单管理                 | 菜单管理       | **P0**       | 动态路由/可见性、父子层级、排序、状态；权限由后端验证                     |
| 权限管理                 | 菜单/按钮权限  | **P0**       | API 资源权限、按钮权限标识、默认拒绝、越权测试                            |
| 字典管理                 | 字典           | **P0**       | 字典类型/项、启停、排序、缓存策略简单可控                                 |
| 系统参数                 | 参数配置       | **P0**       | 非秘密运行参数读写、验证与审计；密钥只用环境/密钥系统                     |
| 操作审计                 | 操作日志       | **P0**       | 操作人/动作/资源/结果/时间/请求ID，敏感字段脱敏                           |
| 登录审计                 | 登录日志       | **P0**       | 成败记录、来源 IP 合规处理、可筛选/保留策略                               |
| 异常与请求日志           | 异常日志       | **P0**       | JSON 结构化日志、错误码、trace/requestId                                  |
| 通用附件上传             | 文件服务       | **P0**       | 文件大小与类型校验、随机文件名、访问控制、本地抽象存储                    |
| 通用 CRUD 模块示例       | 代码生成       | **P0**       | 可复用示范实体（如 `SampleRecord`），字段/校验/API/Web CRUD/测试完整      |
| 代码生成工具             | 代码生成       | **P0**       | 从 schema/元数据生成 DTO/API/前端列表和表单的确定性模板；避免覆盖人工改动 |
| API 文档                 | 系统接口       | **P0**       | OpenAPI、鉴权说明、错误码和示例                                           |
| 通知/公告                | 通知公告       | **P1**       | 站内公告 CRUD、发布范围与阅读状态，仅需求触发                             |
| 在线会话管理             | 在线用户       | **P1**       | 会话列表/撤销/强制下线；需配套可撤销 session 设计                         |
| 定时任务                 | 定时任务       | **P1**       | 仅服务端受控任务和执行日志；禁止任意代码执行                              |
| 部门组织树               | 部门管理       | **P1**       | 组织树、成员归属，需实际组织场景才启用                                    |
| 岗位管理                 | 岗位管理       | **P1**       | 岗位信息及关联，勿与角色混为一谈                                          |
| 数据范围权限             | 数据权限       | **P1**       | 组织/属主范围经服务端过滤，默认不开                                       |
| 导入/导出                | Excel 工具     | **P1**       | CSV/Excel 明确限制、权限、公式注入防护、错误明细                          |
| 系统基础运行指标         | 服务监控       | **P0**       | /health/live、/health/ready、结构化错误及基础 metrics                     |
| 可视化监控控制台         | 服务监控       | **P2**       | 不预建；需要时接标准监控系统                                              |
| 缓存管理/监控            | 缓存监控       | **P2**       | 无 Redis 则不需要                                                         |
| 数据库连接池监控         | 连接池监视     | **P2**       | 使用标准 DB metrics，不复制 RuoYi UI                                      |
| 可视化表单设计器         | 在线构建器     | **P2**       | 属独立产品，不默认实现                                                    |
| 多租户/SaaS/微服务       | 非基础能力     | **X**        | 不预建；确有业务需求另立 ADR                                              |
| 支付、商城、审批、工作流 | 非平台基础     | **X**        | 业务插件开发，不进入脚手架核心                                            |
| 微信小程序端             | RuoYi-App 参考 | **P0**       | 登录、我的、系统导航、最小跨端 CRUD 示范；不复制 PC 全部管理模块          |
| Web 管理界面             | RuoYi-Vue 参考 | **P0**       | 登录、布局、菜单、用户/角色/菜单/字典/参数/日志/文件/代码生成管理 UI      |
| 国际化/主题              | 通用体验       | **P0**       | 简体中文默认、英文结构可扩展；亮/暗主题与响应式基础布局                   |
| 测试/CI/部署             | 工程基础       | **P0**       | lint/typecheck/unit/integration/e2e/build、Compose、README、环境说明      |

## RuoYi 参考原则

官方清单包括用户/部门/岗位/菜单/角色/字典/参数/公告/操作日志/登录日志/在线用户/定时任务/代码生成/API/服务与缓存监控/在线构建器/连接池监视。逐项做取舍，不代表所有原功能照搬。见 https://github.com/yangzongzhuan/RuoYi-Vue 。

## P0 最小产品纵向闭环

创建管理员 → 登录 → 配置角色与 API 权限 → 创建 `SampleRecord` → Web CRUD → 小程序读取/修改同一记录 → 审计日志记录 → 无权限用户访问被拒绝 → 数据迁移/测试/部署全部通过。
