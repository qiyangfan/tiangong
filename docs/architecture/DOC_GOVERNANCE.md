# 文档责任边界

- **README**：是什么、怎么运行、如何部署、模块地图。
- **AGENTS.md**：AI coding 的工作流程与代码审查行为。
- **CONSTITUTION.md**：不可轻易违背的工程原则及冲突优先级。
- **ADR**：稳定的架构决策、背景、替代方案、影响与可推翻条件。
- **OpenSpec specs**：经实现和验收的产品行为；changes：待引入的行为改动。
- **FUNCTION_MATRIX**：能力边界、优先级和 RuoYi 对照；不是运行证据。
- **ACCEPTANCE**：测试/交付的通过门槛。
- **CHANGELOG**：对使用者可见的已发布变更。
- **SECURITY**：漏洞报告与安全基线。

同一规则避免在多个位置复制；交叉引用其他规范。代码行为冲突时先核实实际运行，再纠正规范与代码。
