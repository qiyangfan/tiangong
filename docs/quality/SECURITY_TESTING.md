# 安全与质量基线

## 安全

- 生产默认无演示账户/默认密码；密码 Argon2id 或成熟等效哈希；密码重置单次有效且限时。
- 浏览器优先考虑安全 HttpOnly/Secure/SameSite Cookie 会话，评估 CSRF；小程序平台凭证存储使用适配方案。最终方案记录 ADR。
- Web 后台及小程序均在 API 服务端强制 RBAC；默认拒绝、最小权限，防 IDOR。
- 登录/重置密码限流；不要求 Redis 时采用可明确说明单实例约束的实现。
- 输入验证、输出编码、CORS 白名单、CSRF/XSS/SQL 注入防护、上传白名单、文件访问鉴权。
- 不记录 token、密码、机密配置及敏感正文；审计日志可追溯且有保留策略。
- 开源模板和依赖需进行安全与许可审查；`npm audit` 仅是辅助手段。

## 测试金字塔

- unit：用户权限判断、动态路由映射、参数校验、枚举校验、文件上传约束。
- integration：Prisma 真库、迁移、事务、关联删除、唯一约束、审计写入。
- e2e：登录/退出、权限拒绝、字典管理、用户启停、记录 CRUD、Web/小程序契约演示。
- UI：空态、加载、错误、无权限、分页、表单、响应式和基本可访问性。
- security regression：认证绕过、路径遍历、水平越权、无效 token、暴力破解。

## 可运维

- /health/live 与 /health/ready 区分进程可用和数据库就绪。
- requestId、结构化日志、异常级别、启动配置校验；容器 graceful shutdown。
- 数据库备份恢复流程与迁移兼容性测试，至少一份正式运行指南。
