# ADR-0004: 通用 RBAC 与平台特定会话

状态：Accepted（会话载体待实施验证） | 日期：2026-11-07

## 决策

通用平台必须有用户、角色、权限、菜单四种基本概念。Permission 以 `resource:action` 为 API 授权语义，菜单和按钮关联权限标识用于界面展示。API 默认拒绝未经授权请求。

Web 与微信小程序可以有不同的安全会话载体，不强行共享存储方式；服务端共享鉴权逻辑。登录保护、退出、令牌撤销策略必须在首版定义并测试。

## 未决验证

HttpOnly cookie + CSRF 与小程序 token 策略的集成、安全性、跨域部署行为，做专门安全用例验收。
